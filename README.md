# Atividades de Estrutura de Dados - Java

O projeto segue uma estrutura parecida com os exemplos da pasta `src/estrutura_de_dados` do projeto enviado.

## Organização
- `estrutura_de_dados/lista_encadeada`: classe `No`, implementação `ListaEncadeada` e os 10 exercícios.
- `estrutura_de_dados/mapa`: implementação simples de mapa com arrays e os 7 exercícios.

## Como executar
Abra a pasta `src` na IDE (por exemplo, IntelliJ IDEA). Cada exercício tem sua própria classe com `main`.
Execute a classe do exercício desejado pelo botão de execução da IDE.

Exemplos:
- `estrutura_de_dados.lista_encadeada.Exercicio1Chamada`
- `estrutura_de_dados.mapa.Exercicio1SistemaAlunos`

Não foi usado `HashMap` nem `Collections` prontas. A lista encadeada usa nós ligados por referência; o mapa usa dois arrays, um para as chaves e outro para os valores.

Nos exercícios de lista, alguns registros estão representados como textos para manter a implementação simples, seguindo o estilo básico dos exemplos. Você pode separar esses dados em classes próprias depois, caso a professora peça.
